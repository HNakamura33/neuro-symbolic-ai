## 1. タイトル候補

1. **Symbolic Gates, Not Symbolic Tools: Making Neuro-Symbolic Layers Pay Off in LLM Agents**(記号ゲートであって記号ツールではない: LLM エージェントで記号層に元を取らせる方法)

## 2. アブストラクト(約 250 語、対訳)

> ニューロシンボリック・アーキテクチャは LLM エージェントに知識ベースと決定論的推論器を組み合わせる。記号的接地が信頼性を高めるという前提の下でである。我々は、記号層が*存在するか*よりも*どう取り付けるか*が重要であることを示す。MetaQA マルチホップ質問応答(13.3 万トリプル KB、600 問)において、記号 KB ツールを任意の道具として与えられたエージェントは完全一致 0.790 — 記号ツールを一切持たない純ニューラルな agentic-search ベースライン(0.860)を*下回る*。同一の記号的能力を出力経路上の必須ゲート — 決定論的な回答バリデータと verify-before-final プロトコル、いずれも通過しなければ解答できない — として付け直すと、精度は 0.970 に上がる(McNemar 対 search ベースライン: 判別対 66/0、p=2.7e-20)。さらにニューラルな経路探索を決定論的グラフ走査で置き換える ablation は追加の利得を生まない(0.962、p=0.3): 有効成分は探索の記号化ではなくゲートである。エラー分析がその理由を説明する: 3-hop 失敗の 93% は KB 所属・型検査が機械的に検出できる質問誤読であり、一方で保護的な verify ツールは任意である限り、最も必要な場面ほど使われない(使用率 1-hop 49% に対し 3-hop 12%)。さらに 2 つの実験が「ゲートに何が必要か」を単離する。KB 矛盾監査では、自由に参照される OWL-RL 推論器が 19 件の真の違反を 95 件の疑似違反に増幅した(Precision 0.05)が、provenance を同梱する閉包前の違反列挙器が Precision・Recall を 1.0 に回復し、コストは 75 分の 1 だった。そしてニューラルな検証者は代替にならない: 完了宣言に対する LLM 判定者は誤宣言を統計的に変えられず(p=0.09)、その誤りは生成器と相関する。記号層が価値を生むのは決定論的ゲートとしてであり、ツールとしてでも判定者としてでもない。

*(英語版は約 278 語。venue が 250 語厳守なら、使用率逆転の節「while the protective verify tool … 12% at 3-hop」(−30 語)を削る — §4.6 で再述されるため。)*

## 3. 貢献(Contributions)

1. **対になった証拠を持つ設計テーゼ:** 同一の記号的能力が、任意ツールとして提供されると純ニューラルな agentic ベースラインに負け(0.790 < 0.860)、出力経路上の決定論的ゲートとして強制されると決定的に勝つ(0.970; 判別対 66/0、p=2.7e-20)。取り付け方 — ツールかゲートか — が LLM エージェントにおける記号層の貢献の符号を反転させることの、我々の知る限り初の統制された実証。
2. **有効成分を単離する ablation:** ゲートの上に決定論的経路走査(`kb_path`)を足しても有意な追加利得なし(0.962 vs 0.970、10/5、p=0.3)。利得は出力のゲートから来るのであり、探索過程の記号化からではない。
3. **設計を根拠付ける機構レベルのエラー分析:** (a) 3-hop 失敗の 93% は起点エンティティの属性誤読で、KB 検査で機械的に検出可能; (b) 任意の `kb_verify` は保護的(使用時 +9–12 pt)だが使用率がホップ数と逆転する(49% → 12%)— 助言でなく強制の動機; (c) 見かけの「委譲は QA に有害」は生存バイアス/配管アーティファクト(構造化ハンドオフ分析)であり、エージェントレベルの結論がハーネス効果に交絡され得ることの例示。
4. **KB 監査における第二領域の再現:** 矛盾を含む KB 上の OWL-RL 閉包推論器への自由アクセスは能動的に有害(sameAs 連鎖増幅、19→95 / 20→393 の疑似違反、Precision 0.05、run 間でビット同一の誤予測)である一方、ゲートされた閉包前の `kb_violations` 列挙器+provenance は全 4 グリッド × 2 エージェント構成 × 3 runs で P=R=1.0 を達成し、コストを ~$15 から ~$0.2/run に削減。
5. **非退行対照付きの回復プロトコル:** 過去に失敗したタスクのみをゲート付きプロトコルで再走して 106/126(84%)を回復、同数 126 タスクの対照群で退行ゼロ。
6. **「検証を増やす」と「決定論的に検証する」を分離するネガティブコントロール:** 矛盾仕様 20 問のコーディング完了宣言に対する LLM loop-judge は誤宣言を有意に減らせず(19/20 vs 15/20、Fisher p=0.091)、最も明示的な矛盾層では自己判定より*悪く*、合成含意型の矛盾では強いモデルすら救えない(両条件で誤宣言 2/5)。プロトコルよりモデル能力が支配的(モデル間 19/20 vs 2/20、p=2.9e-08)。ゲートの力は決定論性に由来し、セカンドオピニオンに由来しない。

## 4. 論文骨子

### 4.1 はじめに
- フレーミング: 分野は記号層が LLM エージェントを*助けるか否か*を論じてきたが、答えは結合様式に依存することを示す。任意ツール → エージェントは負荷が高い場面ほど使わず、純ニューラル探索に負ける。必須ゲート → 大差かつ統計的に決定的な勝利。
- テーゼ文: *任意ツールとして取り付けられた記号層は純 LLM の agentic システムに負ける。同じ層を出力経路上の必須ゲートとして取り付ければ大差で勝つ。*

### 4.2 システム
- LLM エージェント+永続 RDF/OWL KB; ツール群(`kb_find`、`kb_sparql`、`kb_verify`、`kb_infer`); 2 つのゲート: `kb_check_answer`(存在・質問との型整合・起点除外 — 「設問意味論を記号検査にコンパイルする」ものとして提示)と verify-before-FINAL プロトコル; 監査用 `kb_violations`(閉包前列挙+provenance 同梱); asserted/inferred タグ。

### 4.3 実験 1 — マルチホップ KGQA(主結果)
- MetaQA、133,582 トリプル、600 問(hop 毎 200)、完全一致、キー `correct`。
- 条件: B0(KB なし)、B2(agentic-grep、記号ツールなし)、C1-rev2(記号ツール任意)、C1-rev5(ツール+ゲート)、C1-rev6(rev5 + `kb_path` ablation)。
- 結果表: 0.193(B0)/ 0.860(B2、hop 別 .935/.810/.835)/ 0.790(rev2、.905/.685/.780)/ **0.970(rev5、.950/.980/.980)** / 0.962(rev6、.950/.990/.945)。McNemar: rev5 vs B2 66/0 p=2.7e-20; rev5 vs rev2 108/0 p=6.2e-33; rev5 vs rev6 10/5 p=0.3。
- 補強証拠としての汚染プローブ: エンティティ ID 摂動で B0 は 0.000 に崩壊、記号条件はほぼ不変 — KB は本当に参照されており、暗記ではない。
- 失敗タスク回復: 106/126(84%)、対照 0/126 退行。

### 4.4 実験 2 — 矛盾監査(第二領域)
- 2×2 グリッド({500,2000} 主張 × {5,20} 矛盾)、3 runs、C1/C2。
- 修正前: Recall ≈1.0 だが Precision は双峰で 0.05 に崩壊; 機構: 矛盾 KB 上の OWL-RL 閉包が sameAs 連鎖の疑似違反を製造し、エージェントがそれを逐語転記(run 間ビット同一の予測)。トリプル単位の provenance 修復: 318 呼び出し、$15.51、R=0.60。
- 修正後(`kb_violations`): 全 24 runs で P=R=1.0、≈$0.2/run。
- 読み方: 監査結果はゲートテーゼの対偶 — *ゲートされていない*記号推論器は無いより悪くなり得る。

### 4.5 実験3 — ネガティブコントロール: LLM 判定者はゲートではない(完了宣言)
- 問い: ゲートの利得は単なる「二度検証する」ことか、それとも検証者が決定論的であることか。決定論的検査を LLM 検証者に差し替えて測る。
- セットアップ: Python 修正タスク 50 問、うち 20 問が意図的な矛盾仕様(実行不能; 3 難度層: direct-example / rule-vs-example / implied; 機械検証済み — 全実行不能タスクの隠しケースに同一入力・異期待値ペアあり)。実行不能での正解 = STALLED 宣言。条件: 自己判定 vs loop-judge の承認必須。誤宣言 = 隠しテスト失敗のままの DONE。
- 結果表(実行不能 20 問での誤宣言):

  | | self | judge | Fisher(self > judge) |
  |---|---|---|---|
  | Haiku 級 | 19/20 | 15/20 | p = 0.091(n.s.) |
  | Sonnet 級 | 2/20 | 3/20 | p = 0.83 |

  能力効果: self Haiku 19/20 vs self Sonnet 2/20、p = 2.9e-08。層別詳細: direct-example では judge が self より*悪い*(Haiku で 5/5 vs 4/5); implied 層は Sonnet を**両**条件で破る(各 2/5)。
- 考察(3 つの読み、いずれもテーゼを支える):
  1. **誤りの相関。** 判定者は同じモデル系列から取られ同じ仕様を読む。したがって同じ誤り分布からの 2 回目のサンプルであり、直交した検査ではない。効いた場面(Haiku の rule-vs-example、2/5 vs 5/5)の機構は仕様全体の読み直し — 厳密性でなく多様性 — であり、多様性は保証には積み上がらない。決定論的ゲートは LLM と独立な誤りモデルを持つ。§4.3 のゲートが買っているのはこの独立性であり、追加ステップ自体ではない。
  2. **能力がプロトコルを支配する。** 完了宣言の信頼性はモデルに追従し(p=2.9e-08)、判定プロトコルには追従しない(p=0.09)。実務的帰結: 弱いモデルへの judge オーバーヘッド(コスト 2〜2.5 倍)はほとんど買い物にならない。その予算はモデル自体か決定論的検査へ。
  3. **難しい層はまさに記号の層。** implied 型矛盾 — 単独ではもっともらしい 2 つの算術制約が連言で UNSAT — は強いモデルを両プロトコルで破るが、機械的には決定可能である: 仕様の要件を SMT 制約にコンパイルすれば STALLED は充足不能性から従う。ニューラル検証の失敗境界が記号検証の入口と一致する — これが仕様→SMT ゲートを future work として動機付け、QA のゲート(§4.3)・監査ツール(§4.4)とループを閉じる。

### 4.6 エラー分析
- 3-hop 失敗: ~93% が起点エンティティの属性誤読(KB と機械的に照合済み); ニューラルベースラインとも共有(全条件失敗 17 件中 12 件で同じ誤読)→ 誤りは質問解釈にあり、記号的に検出可能。
- 任意 verify の使用率逆転(hop 別 49%/…/12%)と条件付き利得 +9–12 pt。
- 2-hop の摂動利得(+0.2)は表層名満足化(returned-pivot / echoed-start)に由来し、エンティティ衝突ではない(6/55)。
- 委譲の注意書き(解決済み): 「強制委譲は有害」は大部分がハンドオフバグだった — 構造化ハンドオフ修正(FINAL 逐語コピー契約)で null 解答 51→12、EM 0.788→0.825 ≈ 非委譲 C2(0.828)、なおニューラルベースライン(0.860)未満。方法論的注記として報告: エージェントレベルの結論はハーネスの配管に交絡され得るし、生存バイアス込みの推定 0.862 は結論を(誤って)反転させるところだった。

### 4.7 関連研究
- **LLM+形式ソルバ**(Logic-LM、LINC、SatLM、Proof of Thought、MCP-Solver): LLM が定式化しソルバが判定する — ただしエピソード毎で、ソルバは呼び出し可能な道具。ツール vs ゲートの取り付け様式や矛盾 KB の失敗事例を研究したものはない。
- **自己検証 / self-refine**(Chain-of-Verification、SelfCheckGPT、self-consistency): 検証器が LLM 自身のため、検証が生成器の失敗モードを継承し、厳格な前提条件にできない。我々の差別化: 検査が**決定論的かつ記号的**(KB 所属、型位置、provenance)で、強制可能な二値判定を返す — そして §4.5 がこの継承を直接測定した(LLM 判定者: p=0.09 n.s.、同じ層で相関した失敗)。FormalJudge(Dafny/Z3 監督)が最も近い形式ゲートの親戚; KG-Guard(KBQA の事後接地性検出)は検出器であり、我々のは構成的かつインライン。
- **KG エージェント推論**(Think-on-Graph、SymAgent、EmbedKGQA 系譜): 推論主体は LLM のままで、記号構造は探索を誘導するのであって出力をゲートしない。
- **形式的主張を持つエージェントメモリ**(Kumiho、Zep、WorldDB、TOKI; STALE/Supersede/DeltaLogic 測定): 永続化と改訂は形式化されるが、解答時の検証はニューラルのまま — 相補的な動機付け。
- 位置付けの一文: 従来の NeSy 研究は記号層が*何を*計算するかを問うてきた。我々はそれがエージェントループの*どこに*結合するかを問い、結合部位が支配的であることを示す。

### 4.8 限界(誠実に)
- **claim 検証 RQ の飽和:** 合成 claims では自明でない全条件(KB 全文貼り付け含む)が全スケールで 1.000 となり判別不能。テーゼの証拠には使わず null として報告。推論必須 claims への agentic-search ベースラインは今後の課題。
- **ベンチマーク構造がニューラルベースラインに有利で、ゲートの形も規定する:** MetaQA はエンティティが逐語で現れ KB テキストが行指向(grep 向き)。ゲートの一成分(起点除外)は MetaQA の解答規約のコンパイルであり、「設問意味論の検査へのコンパイル」の MetaQA 外への一般性は未検証。
- **単一モデル系列・限られたシード:** QA の見出し数値は Sonnet 級 1 モデル・条件毎単一 run+対応あり McNemar。監査は 3 runs/セル。安価モデルでの再現を計画中。
- **合成監査 KB**(≤2000 主張、注入違反); そこでは全文脈ベースラインも P/R 1.0 のため、監査の貢献は機構とコストであり見出し精度ではない。
- ゲートはコストを上げる(600 問あたり ~$38 vs ~$21–22): 精度/コストのトレードオフは明記すべき。
- **ネガティブコントロールの射程:** 完了宣言の実験は手書きの実行不能仕様 20 問・セル毎単一 run で、判定者はエージェントと同じモデル系列。異系列や best-of-N の判定者なら誤りの相関が切れる可能性があり、未検証。主張は「この標準的な判定者構成は決定論的ゲートの代替にならない」に限定する。

### 4.9 結論
- テーゼ再掲; レシピ(出力をゲート、閉包前に列挙、全判定に provenance、そしてゲートは決定論的であること — LLM 判定者は 2 回目のサンプルであって検査ではない); 今後: 矛盾仕様への仕様→SMT UNSAT ゲート(§4.5 の構成的対応物)、ゲート付きカスケード(3-hop の union 上限 0.915)、安価モデル+ゲート構成、自己進化の二重ゲートとの接続。
