# 査読レポート: 「記号層に接地された LLM エージェント」(ドラフト v0.7)

*査読日: 2026-07-19。査読者: 独立コンテキストの査読エージェント(本セッションの実験経緯を知らない状態で docs/paper-draft.md v0.7 を精読し、主要数値を results/*.jsonl・data/*/ から独立に再計算)。前ラウンド査読 docs/review-paper-draft-v0.6.md(Weak reject, confidence 4)および著者回答 docs/referee-response-v0.6.md を照合した。*

**査読方式について**: v0.6 と同じ厳格度で、本文・Abstract・貢献リスト・§4/§8 の主要数値を生データから独立再計算した。今回の重点は (a) 新規 held-out(構築の妥当性そのものを含む)、(b) 新規 B2g アブレーションと 2 つの McNemar 分解、(c) 3-run 分散と prompt_rev の凍結、(d) v0.6 の数値修正が本文に正しく反映されているか、(e) B2g の grep ゲート契約(QA_GREP_VERIFY)が記号ゲート(QA_VERIFY / kb_check_answer)をハーネスコード上で公正に鏡写ししているか、である。**結論から言えば、再計算したすべての数値が本文と一致した — 不一致はゼロである。** 前ラウンドで残った M1・M3 の本質的懸念は新規実験で実データにより解消されており、中心テーゼは held-out 上で成立する。残る弱点は算術ではなく、設計・推論・証拠の広さに関するものである。

## Summary

著者らは LLM を「理解と記号表現への定式化」に限定し、事実の保存・推論・検証を決定論的記号層(RDF+OWL-RL / CSP / Z3)に委ねるエージェント `nsai` を構築した。中心主張は、記号層の寄与の符号を決めるのは層の**有無**でなく**結合様式**(任意ツール vs 出力経路上の強制ゲート)だというものである。v0.7 は v0.6 の Weak reject に対し、(1)開発に一切用いなかった held-out 600 問での rev5 再測定(M1)、(2)ニューラル版ゲート B2g による有効成分の分解(M3)、(3)中心 2 条件の 3-run 化(M5)を新規に加え、M2/M6/M7 の数値誤りを修正した。加えて貢献 1 を「結合様式が符号を反転させる」から、より鋭い**分解された主張**(出力経路への検査強制が主効果 +.090、決定論性が有意な残余 +.020)へ書き換えた。この書き換えは査読の代替仮説を否定でなく取り込む誠実な対応であり、テーゼの証拠強度をむしろ上げている。

## Strengths

- **数値の検証可能性が引き続き最上位。** 新規結果を含め、EM(全条件ホップ別)、6 対の McNemar、held-out 構築(重複ゼロ・KB の sha256 一致・meta.json のシード/除外)、B2g 分解、3-run 分散、4c の全セルと Fisher・検出力・Newcombe CI、監査の崩壊 pred サイズ・rev4 24/24・$15.51/343/318、C2f null 分解、matched-300 のホップ別デルタ — **すべて生データから一致した(§検証記録)**。この分野の投稿として例外的である。
- **M1 への回答が構築レベルで健全。** held-out 600 問は seed 7・各ホップ 200・開発 600 問と**質問テキスト重複ゼロ**(独立確認)、KB は開発セットと**バイト同一**(sha256 一致、独立確認)。rev5 は凍結 worktree の PROMPT_REV=5 から走り、全 600 レコードで prompt_rev=5(独立確認)。held-out rev5 0.977 ≥ 開発 0.970、分離 McNemar 61/5(p=2.63e-13)も再計算一致。「開発セット上の値」という v0.6 の割引理由は、少なくとも同一ベンチマーク内では消えた。
- **M3 への回答がテーゼを分解して強化。** B2g(grep 版ゲート)の追加により、利得を「プロトコル強制 +.090(p=9e-13)」と「決定論性 +.020(p=0.0227)」に分解した。ハーネスコード(`QA_GREP_VERIFY` vs `QA_VERIFY` + `kb_check_answer`)を精査した結果、grep 契約は記号ゲートを段階ごとに公正に鏡写ししており(§後述の検証(e))、「ニューラル版の同じゲート」という主張は概ね妥当である。査読の反論を握り潰さず、データで部分的に認めた上で残余を測る姿勢は方法論的に模範的。
- **誠実な限界の開示。** held-out が同一ベンチマークであること、ゲート**設計**自体が開発セットの誤り分析由来であること、起点除外検査が MetaQA 規約由来であること、摂動下では絶対 EM が .977→.887 に落ちること、を §7 と §4.2 に明記。4c の逐次デザイン(初期 5 問後に 15 問追加)も開示され、`coding4c-*-inf15.jsonl` の mtime が base より後であることも独立確認できた。
- **v0.6 の数値誤りが全件正しく修正。** 5→95(19 倍)、matched-300 −.037、Agent キー、343/318、判別対 5/10 の順序 — すべて本文に正しく反映され、stale な「19 件」は残っていない。

## Major concerns

**M1'. held-out・摂動 held-out・B2g がいずれも単一 run であり、run 分散の反論(M5 の 3-run 化)は開発セットにしか及んでいない。**
3-run 化(表10)は開発セットの rev5・B2 に対してのみ行われ(独立確認: rev5 .970/.970/.973、B2 .860/.850/.863)、M1 の看板数値を担う held-out rev5(0.977)・held-out B2(0.883)・摂動 held-out rev5(0.887)、および M3 の B2g(0.950)は**各 1 run**である。すなわち「単一 run は危うい」という自己批判(監査の双峰性)への回答が、最も新しく最も重要な数値には適用されていない。McNemar は項目対応を扱うため 61/5 のような大差が run 分散で消えることは考えにくいが、後述の M3' の +.020 のような微差はこの限りでない。**最低限 held-out rev5・B2 と B2g を各 2–3 run 化**し、held-out 上でも分散が開発セット並み(range ≤.013)に収まることを示すべきである。

**M3'. 再フレーミングされた新しい看板主張「決定論性が有意な残余 +.020 を上乗せする」が、単一 run・多重比較未補正・run 分散帯と同オーダーという三重の脆さを抱える。**
これは v0.7 で貢献 1 の核に昇格した主張であり、精査に値する。(i)B2g は 1 run のみ。(ii)rev5 vs B2g の p=0.0227 は 5% を辛うじて下回るのみで、本論文が走らせた多数の McNemar を Bonferroni 等で補正すれば n.s. に転じうる。(iii)残余の大きさは判別対 18/6 = 純 12 問 = .020 だが、これは B2 自身の run 間変動(.850–.863、range .013 ≈ 8 問)と同オーダーである。McNemar は対応ありなので run 分散の一部は相殺されるが、B2g が単一 run である以上、別 run で B2g が .955–.960 に振れれば残余は縮み有意性を失いうる。**主張の強さをデータに合わせるべき**: 「決定論性は有意な残余を上乗せする」は「決定論性は小さいが正方向の残余を与える(単一 run、未補正 p=.023、要追試)」に弱めるか、B2g を複数 run 化して残余の頑健性を示すこと。なお grep 契約が記号ゲートより explicit なレシピを与えている点はむしろ B2g を有利にし残余を保守側に押すため、+.020 は下限寄りと解せる — が、それでも単一 run の脆さは残る。

**M2'. 摂動 held-out に強ベースライン(B2)の比較アームが無く、「摂動下でもゲートは +.085 優位」は異なるセット・異なる rev の弱いベースラインとの比較である。**
`results/` に `metaqa-heldout-pert-B2` は存在しない(独立確認)。摂動 held-out rev5 0.887 が比較されている相手は、**開発セットの rev2 摂動 C1(0.802)**である。これはセット(held-out vs 開発)・rev(5 vs 2)・条件(ゲート vs 任意ツール)の 3 点が同時に異なる交絡した比較であり、本論文が最も強い非記号ベースラインと位置付ける B2 に対する摂動 held-out 上の分離を示していない。摂動下の主結論(§4.2 末尾「相対優位は保たれるが絶対値は落ちる」)自体は原名 vs 摂動の対応あり比較(63/9、p=4.18e-11、独立確認)で正直に枠付けられているが、**+.085 という優位の数字は撤回するか、摂動 held-out 上に B2 アームを 1 本足して同一セット・同一摂動での分離**に置き換えるべきである。1 条件の追加で済む。

**M4'. QA 主張の外的妥当性が依然として単一ベンチマーク(MetaQA)+単一モデル系列に集中している。**
held-out は M1 を解決したが、それは「同一ベンチマークの未使用サンプル」であって cross-benchmark ではない(著者も §7 で明記)。ゲートの一成分(起点除外検査)は MetaQA 解答規約を記号検査にコンパイルしたものであり、その一般性は未検証である。当初計画の ProofWriter / PrOntoQA / 2WikiMultiHopQA / FEVER / CLUTRR はいずれも未実施、RQ1 は飽和で null、4a も null、4d は 9/500 で保留。**テーゼ「結合様式が符号を反転させる」の一般性は、少なくとも 1 つの別 KGQA ベンチマーク(2WikiMultiHopQA 等)での再現がなければ、MetaQA の形状(逐語エンティティ・行指向 KB で grep が強い)に条件付けられた知見の域を出ない。** これは v0.6 から持ち越しの構造的限界であり、本ラウンドの新規実験は同一ベンチマーク内での堅牢化に留まる。first-tier の会議基準では、この 1 点が accept と borderline を分ける。

## Overall assessment

**Weak accept**(confidence: **4**)。

v0.6 の 2 つのブロッキング懸念(M1: held-out、M3: ニューラル版ゲートの分離)は、いずれも**新規かつ検証可能な実データで実質的に解消**された。held-out の構築(重複ゼロ・KB バイト同一・シード/除外・prompt_rev 凍結)は独立に健全性を確認でき、rev5 0.977 ≥ 0.970・分離 61/5 は適応的過学習の割引を不要にする。B2g 分解は査読の代替仮説を否定でなく取り込み、テーゼを「出力経路への検査強制(主)+ 決定論(残余)」へ誠実に精緻化した。数値誤りは全件修正され、再計算した全数字が一致した — 証拠の信頼性は一流会議水準を超える。中心テーゼ「同一の記号能力でも結合様式が寄与の符号を反転させる」は、held-out 上で成立すると判断する。

accept 圏に一歩届かない理由は 3 点に集約される: (i)看板数値(held-out・B2g)が単一 run で、本論文自身の分散反論が及んでいない(M1')。(ii)新たに核へ昇格した「決定論残余 +.020」が単一 run・未補正 p=.023・run 分散帯と同オーダーで脆い(M3')。(iii)QA テーゼの外的妥当性が単一ベンチマーク・単一モデル系列に留まり、cross-benchmark 一般化が無い(M4')。(i)(ii)は追試 2–3 本、(ii)は主張の弱化でも対応可能であり、(iii)のみが実質的な追加実験を要する。(iii)を別 KGQA 1 つで満たせば明確な accept と判断する。現状でも、問いの新しさ・証拠の検証可能性・誠実な限界開示は投稿に値する水準にある。
