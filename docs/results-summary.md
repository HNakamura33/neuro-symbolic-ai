## RQ2 — 規模とマルチホップ QA(実験2)

### 合成スイープ(s100–s5000、claims+QA、sonnet/haiku)

- **精度では B1(全文インライン)は劣化しない**(QA 0.938–1.000)。文脈崩壊仮説は
  5000 triples までは不成立。
- **コストが決定的に分かれる**: B1 は線形増加(sonnet $1.5→$45、haiku $0.7→$17)、
  C1 はフラット($1.5 前後)、C2 もフラット($2.3–2.5 / haiku $0.84–0.89)。

### MetaQA(133,582 triples、600 QA、EM 1/2/3-hop)

| 条件 | 原版 | 全体 | コスト | 摂動版 | 全体 |
|---|---|---|---|---|---|
| B0 | .360/.110/.110 | .193 | $5.92 | **.000/.000/.000** | .000 |
| B1p(oracle-BFS+one-shot) | .940/**.945**/.585 | .823 | $126.54 | (スキップ) | — |
| B2(agentic-grep) | .935/.810/**.835** | **.860** | $22.28 | 未実施 | — |
| C1(記号ツール) | .905/.685/.780 | .790 | $21.23 | .810/.930/.665 | .802 |
| C2(nsai フル) | .895/.765/.825 | .828 | $29.49 | .810/.920/.630 | .787 |
| C2f(強制委譲) | .870/.720/.775 | .788 | $46.83 | — | — |

主要な知見:

1. **汚染プローブ決定打**: 実体名を一意 ID に置換すると B0 は完全崩壊(0.000)、
   記号条件は全体 EM ほぼ不変 → B0 の正解は記憶由来、C1/C2 は本当に KB を検索している。
2. **文脈の壁を破るのはエージェント性であって記号接地ではない**: B1p の 3-hop は
   gold-in-context 63% の構造的上限で 0.585 止まり。反復探索できる条件(B2/C1/C2)は
   壁を破るが、**grep しか持たない B2 が 0.835 で最高**。記号ツールの EM 上乗せはない。
   → RQ2 の仮説は「記号層接地は劣化しない」から「反復探索が劣化を防ぐ」に書き換え。
   MetaQA は grep に有利な構造(質問文に実体名が逐語で出る・行指向 KB・推論不要)である
   点は明記する。
3. **2-hop の失敗モードは実体リンク曖昧性**: 摂動(一意 ID 化)で C1 +0.245、
   C2 +0.155 と 2-hop だけ大幅改善(両条件で再現)→ 原版の 2-hop 低下は経路追跡でなく
   同名実体の曖昧性解消の失敗。逆に 1/3-hop の低下(−0.08〜−0.20)は表層手がかり・
   事前知識への部分依存を示唆。
4. **委譲(subagent)は QA では損**: C2 の自発委譲 0/600。C2f で強制すると 600/600
   委譲するが EM は全ホップで C2 未満(0.788 vs 0.828)かつコスト 1.6 倍。
   委譲不履行は「意欲」でなく合理的判断 — サブエージェント境界の情報損失が原因。
   探索委譲の損益分岐(RQ2 後半)は QA タスクでは負け側で決着。

## RQ3 — 矛盾監査(実験3、a500/a2000 × c5/c20 × 3 run)

| 条件 | Precision | Recall | コスト/グリッド |
|---|---|---|---|
| B1 | **12/12 run で P=R=1.00** | 同左 | $0.7–2.2 |
| C1 | 双峰(1.00 or ~0.05)、12 run 中 7 で崩れ | ほぼ 1.00(1 グリッドで 0/0.5/0.6) | $3–30 |
| C2 | 双峰(12 run 中 4 で崩れ) | ほぼ 1.00(1 run 0.35) | $0.7–1.8 |

- ≤2000 triples では B1 が完勝。文脈崩壊はここでも不成立。
- C1/C2 は検出(Recall)はできるが、**報告・定式化層で過剰列挙**して Precision が
  双峰的に崩れる。誤りが定式化層に局在するのはエラー分析の主素材。
- C2 のコストは C1 の 1/4–1/40(委譲のコスト優位はこのタスクでは再現)。

## RQ4 — ハイブリッドコーディング(実験4、sonnet run 0)

- **4a(バグ修正)**: QuixBugs plain 31/31 vs nsai 30/31、bugsuite 30/30 vs 30/30。
  分離なし、nsai は 2.6–3.7 倍コスト。sonnet 単体で天井。
- **4b(テスト生成・変異検出)**: 分離は **suite validity** で出た —
  EvalPlus llm 80% vs testgen 95%、bugsuite llm 50% vs **testgen 100%**。
  有効 suite 上の kill 率は同等(0.930–0.972)。testgen は 12–14 倍コスト。
  物語: docstring から推測した LLM 直書きテストは難仕様で半分壊れる、
  ソルバー由来テストは仕様が難しくても正しさを保つ(「記憶可能な複雑さを超えてから
  効く」パターンの 4b 内での実証)。
  - EvalPlus の 0.73 天井は**等価変異体**が原因(HE-39 の生存 17 = oracle 等価 17)。
    plus-tests killability oracle で正規化すると全セル 1.000 → EvalPlus 本表は
    validity+コストのみ、正規化スコアは付録。判別軸は bugsuite。
- **4c(完了宣言プロトコル)**: self と loop-judge が完全一致
  (hidden 30/30、早期完了 0、STALLED 検出 5/5)。judge は 8.9 倍コスト。
  sonnet 単体で天井 — haiku 追試が分離の見込み筋。

## 論文の主張構造(B2 後の確定版)

1. 汚染プローブ: 記憶ベース性能は摂動で消える。記号接地(と agentic 検索)は残る。
2. 文脈上限は one-shot の構造問題で、**エージェント性**が破る(B1p→B2)。
3. 記号層の固有価値は EM でなく: (a) **コストのフラット性**(B1 線形 vs C1/C2 定数)、
   (b) **検証可能性**(kb_verify で機械検証できる根拠パス vs 検証不能な grep 連鎖)、
   (c) **ソルバー由来テストの validity**(4b)、(d) 推論必須タスク(RQ1 — 要 B2 追試)。
4. 委譲はタスク依存: QA では精度・コストとも損(C2f)、監査ではコスト 1/4–1/40(C2)。
5. 誤りは定式化・報告層に局在(監査 P 崩れ、QA 2-hop 実体リンク)— 記号層自体は健全。
